Dog Query App (TanStack Query Project)

Project Description
This project is a React application built with Vite and TanStack Query. It fetches data from the Dog API and displays:

- List of dog breeds
- Breed details
- Dog facts
- Dog groups

The app demonstrates API fetching, caching, loading states, and error handling using TanStack Query.

---

Features

- Fetch all dog breeds
- View individual breed details
- Display dog facts
- Display dog groups
- Loading and error state handling
- Responsive UI styling

---

Technologies Used

- React
- Vite
- TanStack Query
- JavaScript (ES6+)
- Dog API (https://dogapi.dog)
